The Horror Unreal Engine 5 template.
This template helps developers quickly prototype horror games in UE5.

---

## FEATURES:
* **Camera Shake System**: Dynamic camera shaking effects to enhance immersion and impact.
* **Locked Doors & Keys**: Advanced locking system where specific keys are uniquely linked to corresponding doors.
* **Flexible Interaction System**: A highly versatile and scalable framework that serves as the foundation for all interactable objects and world mechanics.
* **Inventory System**: Fully functional inventory tracking with seamless item usage and dropping mechanics.
* **Physics & Object Manipulation**: Ability to pick up, move, and manipulate physical objects in real-time, ideal for environmental puzzle design.
* **Item Inspection**: Detailed, *Resident Evil*-style 3D inspection system allowing players to examine items closely.
* **Flashlight & Battery Mechanics**: Functional flashlight gameplay with power depletion and consumable batteries for recharging.
* **Surface-Based Footsteps**: Footstep sound effects that dynamically change depending on the surface type.
* **Smart AI Enemy**: Advanced AI equipped with sight and sound perception components, built utilizing a State Tree for realistic behaviors (Patrolling, Searching, Suscpect, Chasing, etc.).
* **Save & Load System**: System to save game progress.
* **Main & Pause Menu**: Basic user interface including a main menu, settings, and pause menu.
* **Game Over System**: Smooth transition mechanics for player death.
